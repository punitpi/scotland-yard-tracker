# Scotland Yard Tracker

A real-time tracker application for the Scotland Yard board game.

## Features

- Track player movements on digital devices while playing the physical board game
- Real-time synchronization across all connected devices
- Keep track of Mr. X's movement history
- Support for all transport types in the game

## Setup

1. Clone the repository
2. Install dependencies
3. Start the development servers


## Technologies Used

- Backend: Node.js, Express, Socket.IO, MongoDB
- Frontend: React, React Router, Socket.IO Client

## Game Rules

Scotland Yard is a board game where one player takes on the role of Mr. X, a fugitive hidden somewhere in London, while the other players are detectives trying to track him down. This app helps track the movements of all players without needing to use the paper logs included with the game.
